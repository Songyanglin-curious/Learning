# 运行线程启动与等待示例

在 PowerShell 中执行以下命令。需要 JDK 11 或更高版本。

```powershell
Set-Location 'D:\Learning\Java\examples\04-thread-start-join'
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
java '-Dfile.encoding=UTF-8' Main.java
```

这两行分别为当前 PowerShell 控制台和本次 Java 进程指定 UTF-8。

一种可能的输出如下。

```text
主线程开始
主线程继续工作
子线程开始
子线程工作结束
全部结束
```

多运行几次，可以观察“主线程继续工作”可能出现在两条子线程输出之前、之间或之后。每次运行中，`join()` 都会让主线程等到子线程结束，再打印“全部结束”。
