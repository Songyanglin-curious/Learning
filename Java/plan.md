# Java 学习计划

## 学习目的与基础

依据[廖雪峰 Java 教程](https://liaoxuefeng.com/books/java/introduction/index.html)学习，建立能够理解、判断和使用 Java 的知识体系。已有 C# 基础，共通概念可借助对照理解，重点辨别 Java 自身的语义和边界。暂未指定额外的业务项目或职业目标，不据此扩大学习范围。

## 目标能力

- 解释源码、字节码、JVM 与依赖查找的关系，识别运行和版本边界。
- 理解类型、对象、引用、继承、多态、异常、泛型等核心语义，判断典型代码行为。
- 按需求选择常用类型、集合、IO 与时间能力，说明保证、限制和代价。
- 遇到不确定行为时查阅可靠文档，并在有必要时借助 AI 构造最小实验；以实际结果而非生成代码验证疑问。

## 知识地图与建议路线

| 主题 | 核心关系与问题 |
| --- | --- |
| 入门与基础语义 | 编译运行 → 类型、值与引用 → 控制流程、数组与输入输出 |
| 面向对象与核心类 | 类与实例 → 继承和多态 → 抽象与接口；字符串、数值及数据表达 |
| 异常与日志 | 失败怎样传播、资源怎样收尾，以及怎样报告和定位问题 |
| 反射、注解与泛型 | 运行时类型信息、元数据处理与编译期类型约束之间的边界 |
| 集合 | 保存什么 → 判等、顺序和共享行为 → 实现机制与操作代价 |
| IO | 文件与路径 → 字节和文字 → 读写过程与资源边界 → 按用途补齐 |
| 日期与时间 | 时间含义 → 类型选择 → 时区转换 → 运算与文本边界 |
| 教程后续内容 | 按教程目录及实际问题继续检查覆盖；尚未逐项规划，不提前建立空笔记或必做任务 |

这张地图用于导航，不是解锁顺序。当前从哪里接续见 [进度](progress.md)，日期与时间的具体路线见 [专题计划](notes/Java日期与时间学习计划.md)。允许跳转、回顾和兴趣探索。

## 深度与范围

沿用既有学习偏好，不新增更高要求：

- **L1 · 认知**：常规 API、配置和工具选项，知道用途、能力入口及查阅途径，不要求逐项背诵。
- **L2 · 理解与判断**：运行机制、核心语义、能力边界、常见陷阱和方案权衡，是主要学习重心。
- **L3 · 实践与深入**：具体疑问需要验证时安排实验；性能、源码与复杂故障按实际需要展开，不作为所有主题的统一完成要求。

以能解释关键关系、判断典型场景和说明限制作为阶段目标；不能仅凭读完章节、单次答对或 AI 生成实现认定掌握。不设置学习时长、打卡、固定练习量或完成期限。
