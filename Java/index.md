# Java 学习入口

依据[廖雪峰 Java 教程](https://liaoxuefeng.com/books/java/introduction/index.html)学习 Java，以教程检查知识覆盖，重点理解能力、核心语义、机制、边界及与 C# 的异同。不是新增一套独立课程，也不要求按教程逐节推进。

## 继续学习与调整方向

| 入口 | 内容摘要 | 使用场景 |
| --- | --- | --- |
| [学习计划](plan.md) | 既有目标、知识地图、深度与学习边界 | 判断学什么、为什么学，以及需要深入到哪里 |
| [当前进度](progress.md) | 阶段状态、证据限制、待回顾问题和接续位置 | 跨会话恢复学习，避免从头开始或误用旧待办 |
| [日期与时间专题路线](notes/Java日期与时间学习计划.md) | 时间语义、类型、时区、运算、文本边界与旧 API 的问题路线 | 开始当前已建立计划的主题，或查看具体问题安排 |

## 来源与限制

- 主要来源：[廖雪峰 Java 教程](https://liaoxuefeng.com/books/java/introduction/index.html)。具体 API 与版本边界按实际 JDK 和官方文档核对。
- 当前状态以 [进度快照](progress.md) 为统一入口，集合、IO 的证据细节仍保留在原专题记录中。
- Java 资料统一归入本领域：知识笔记放在 `notes/`，验证代码放在 `examples/`；根目录不存放 Java 专题资料。
- 有笔记不等于已经掌握，已讨论不等于已运行验证；不默认扩展到独立项目、完整框架课程或性能调优任务。
