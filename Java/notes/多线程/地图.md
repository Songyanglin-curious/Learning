**计算机如何同时处理多个任务？**

进程、线程、CPU 调度、并发与并行、阻塞与异步。我们今天正在建立这部分认识。

**多个线程怎样正确地协作？**

共享数据、竞态条件、可见性、原子性、锁和死锁。这是理解多线程为什么难的核心。

**怎样合理管理大量并发任务？**

线程创建的成本、线程池、任务队列、Future、CompletableFuture、虚拟线程。它们解决不同的资源管理和任务组织问题。

**真实后端程序怎样使用并发？**

Spring Boot 请求处理、数据库调用、定时任务、消息消费、后台计算，以及应该避免多线程的场景。



* **推荐起点**：拆解“为什么两个线程同时执行 `count++` 一万次，最后结果却小于两万？”——把这个微观过程看懂，你对抢占式调度、竞态条件和锁的必要性就彻底清晰了。
* 如果你更关心**实际写代码怎么用**，也可以直接从“线程池为什么比手动 `new Thread` 好，以及 `CompletableFuture` 和前端 `Promise` 的异同”聊起。
